# 부록 — Antigravity 로그인과 인증

1강 본편에서는 **설치와 실행까지만** 다룹니다.
인증 절차는 화면을 그대로 따라가면 되는 부분이라 여기로 옮겼습니다.

## 로그인 방식 선택

`agy` 를 처음 실행하면 로그인되어 있지 않습니다. 두 가지 중 고릅니다.

1. **Google OAuth** — 가장 간단합니다. 이걸 고르세요.
2. Google Cloud 프로젝트 사용 — 조직 계정을 쓰는 경우

## 인증 링크 열기

인증 URL이 터미널에 출력됩니다. 링크를 클릭하거나 복사해서 브라우저에 붙여넣습니다.
리다이렉트가 안 되면 브라우저에 뜬 **코드를 터미널에 붙여넣으면** 됩니다.

## 링크가 잘려 보일 때

터미널 폭보다 URL이 길면 줄이 끊겨 보입니다. 폰트를 줄이면 한 줄로 보입니다.

```
Ctrl + -
```

명령 목록을 파일로 저장해서 보는 방법도 있습니다.

```
agy --help
```
```
agy --help > help.txt
```

## 인증 진행

브라우저가 열리면 계정을 선택합니다. 완료되면 터미널로 돌아옵니다.
이제 Claude Code와 나란히 쓸 수 있습니다.
