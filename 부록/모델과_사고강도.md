# 부록 — 모델 · 사고 강도 · 세션 이어하기

1강 본편에서 덜어낸 내용입니다. **처음에는 몰라도 됩니다.**
기본값 그대로 써도 강의 전체를 따라오는 데 지장이 없습니다.
익숙해진 뒤에 이 문서를 보세요.

## 모델 고르기 — `/model`

```
/model
```

| 모델 | 언제 |
|---|---|
| Sonnet | 일상 작업에 효율적 |
| Opus | 복잡한 작업에 강하다 |
| Haiku | 짧은 답을 가장 빠르게 |

- 고른 모델은 **새 세션의 기본값**으로 저장됩니다
- `s` 를 누르면 **이번 세션에만** 적용됩니다

## 사고 강도 — `/effort`

```
/effort
```

`low` 부터 `max` 까지 단계로 고릅니다. 오른쪽으로 갈수록 더 깊게 생각하는 대신
**토큰을 많이 씁니다.** 어려운 작업에만 올려 쓰세요.

## 세션 이어하기

```
resume
```

이전 대화 목록이 뜹니다. 검색해서 고르면 **문맥을 그대로 이어받습니다.**
어제 하던 작업을 오늘 이어서 할 때 씁니다.

## 인증이 만료됐을 때

`API Error: 401` 또는 `OAuth token expired` 가 보이면 인증이 만료된 것입니다.

```
/login
```

다시 인증하면 됩니다. 끝낼 때는:

```
/exit
```
