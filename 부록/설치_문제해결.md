# 부록 — 설치가 막혔을 때

## `node`를 찾을 수 없다고 나온다

1. 터미널을 **완전히 닫았다가 새로** 엽니다. 설치 직후에는 PATH가 반영되지 않습니다.
2. 그래도 안 되면 Node.js를 다시 설치합니다.

```
node -v
```
```
npm -v
```

## `git`을 찾을 수 없다

`git : 용어가 cmdlet... 이름으로 인식되지 않습니다` 또는 `command not found: git`.

윈도우에는 git이 기본으로 깔려 있지 않습니다. GitHub 가입과는 별개입니다.

1. https://git-scm.com/downloads 에서 내려받습니다
2. 설치 옵션은 **기본값 그대로** 넘깁니다
3. **터미널을 새로 열고** `git --version` 으로 확인합니다

이것이 안 되면 2강의 `git clone`, 4강의 스킬 설치, 5강의 `git push`가 모두 막힙니다.

## `claude`를 찾을 수 없다

전역 설치가 끝났는지 확인합니다.

```
npm list -g --depth=0
```

## API Error: 401 (OAuth token expired)

인증이 만료된 것입니다. Claude Code 안에서 다시 로그인합니다.

```
/login
```

## npm 권한 오류 (EACCES)

관리자 권한으로 설치하지 말고, 전역 경로를 사용자 폴더로 옮깁니다.
[설치옵션과_다른환경.md](설치옵션과_다른환경.md) 마지막 절을 보세요.

## 한글 폴더 이름에서 오류가 난다

작업 폴더 경로에 한글이나 공백이 있으면 도구에 따라 문제가 생깁니다.
`C:\work\myproject` 처럼 영문 경로에 폴더를 만드는 쪽이 안전합니다.

## 터미널 글씨가 너무 작거나 링크가 잘려 보인다

```
Ctrl + -
```

폰트를 줄이면 잘리지 않고 전체가 보입니다. 출력이 길면 파일로 저장해 여세요.

```
agy --help > help.txt
```
