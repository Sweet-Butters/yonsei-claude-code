# 부록 — 설치 옵션과 다른 환경에서의 설치

> 본편 영상은 **강사와 같은 환경(Windows)** 하나만 시연합니다.
> 다른 환경을 쓰거나 설치 동작을 바꾸고 싶을 때만 이 문서를 보세요.

## Antigravity — macOS · Linux · WSL

```
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

설치 위치:

```
~/.local/bin/agy
```

새 터미널을 열어야 PATH가 적용됩니다. 바로 확인하려면:

```
export PATH="$HOME/.local/bin:$PATH"
```

## 설치 옵션 플래그

| 플래그 | 하는 일 | 언제 쓰나 |
|---|---|---|
| `--skip-path` | 셸 프로필의 PATH를 건드리지 않음 | PATH를 직접 관리하고 있을 때 |
| `--skip-aliases` | 레거시 셸 별칭을 갱신하지 않음 | 기존 별칭을 유지하고 싶을 때 |

사용 예:

```
curl -fsSL https://antigravity.google/cli/install.sh | bash -s -- --skip-path --skip-aliases
```

## Claude Code — 환경별 참고

Node.js만 있으면 설치 명령은 모든 환경에서 같습니다.

```
npm install -g @anthropic-ai/claude-code
```

권한 오류가 나면(macOS · Linux) npm 전역 경로를 사용자 폴더로 옮기는 것이 안전합니다.

```
npm config set prefix ~/.npm-global
```
```
export PATH="$HOME/.npm-global/bin:$PATH"
```
