## 5강 — 만든 봇을 24시간 배포하기 (21장)

**세 줄 요약**
1. 내 컴퓨터를 꺼도 도는 상태로 만든다 — GitHub Actions가 10분마다 대신 돌린다.
2. 키는 코드가 아니라 GitHub Secrets에 넣는다.
3. 실패하면 로그를 읽고 고치는 것까지가 배포다.

| 절 | 내용 |
|---|---|
| 01 | GitHub에 올리기 — `.env` 는 올리지 않는다 · Secrets 등록 |
| 02 | 배포 스킬로 자동화 — 워크플로는 이미 들어 있다 |
| 03 | 돌아가는 것 확인하고 운영하기 — 상태 기록 · 봇에게 명령 |
| 04 | 공개하고 마무리 — README · 비용 0원 |

**산출물** 24시간 도는 알림봇 저장소
**스킬이 대신 못 하는 것** — GitHub 저장소 생성, Secrets 5개 웹 등록, Actions 실행 버튼
**주의** 반드시 `mail-notifier/` **폴더 안에서** 진행한다. 3강이 성공한 적 있어야 시작할 수 있다.
